# AGENTS.md

## Summary

`{{name}}` is a single-crate Rust `{{archetype}}` project, generated by
[rust-foundry](https://github.com/robertguss/rust-foundry-cli) from a closed
catalog. This file is the agent/human entry point — start here, not by
grepping every crate doc.

## Authority

There is no separate spec/plan copy in a generated project: this repo _is_
the source of truth. If you added a `docs/` folder with design notes, link it
here.

## Canonical commands

Primary gate (run before claiming any change done):

- `cargo fmt --check`
- `cargo clippy --all-targets -- -D warnings`
- `cargo test`

Prefer `just check` (see `justfile`) when `just` is installed; it runs the
same three commands. Fall back to the cargo commands above otherwise.

## Definition of done

1. Change compiles and the primary gate above passes.
2. No secrets committed (see Boundaries).
3. Relevant skill used when applicable (see Skills).

## Layout

```text
src/            # crate source (see src/main.rs for the entry point)
Cargo.toml      # package manifest
justfile        # local dev command surface (fmt/clippy/test)
.github/        # CI (Linux only; never add Windows jobs)
```

## Skills

- `.agents/skills/quality-gates/` — how/why for the primary gate above
- `.agents/skills/add-subcommand/` — adding a new CLI subcommand

## Boundaries (forbidden)

- No `CLAUDE.md` / `.claude/` defaults — this project is agent-tool-neutral
- No default MCP kitchen-sink config
- No secret material in Project Specs, code, or commit history
- Do not invent Windows support (hosts, CI jobs, installers)
- Stay within the single-crate v1 scope; do not restructure into a workspace
  without an explicit owner decision

## Why these defaults (teach-as-you-go)

- **Single crate, not a workspace:** simplest thing that works for a CLI;
  split later only if you actually need multiple publishable crates.
- **`just` with a cargo fallback:** `just` gives short memorable commands,
  but nothing here _requires_ installing it — the cargo commands are always
  authoritative.
